# Grid-V2.0 风控机制重构 · 最终联动方案 V2（修正触发顺序打架）

> 修正 V1 的致命 bug：回补触发30% < 单向防御60%，导致单向防御永远不触发。
> 核心：**触发值必须递增**，且每个机制在其区间内独占，不重叠。

---

## 〇、触发顺序修正（关键）

**问题**：V1 里"回补30% < 单向防御60%"，30%就回补了，60%的单向防御永远到不了。

**修正原则**：失衡率从小到大，机制按**阈值递增**顺序触发，每个机制在自己的失衡区间内独占：

```
失衡率 0% → 20% → 30% → 40% → 50% → 60%+ ...
       收网    回补    回补    回补    [全平兜底]
       区间    区间    区间    区间
```

---

## 一、六个机制（修正触发值）

### ① 档位密度网（收网）· 最轻
- 5档失衡率滑块(如20/30/40/50/60) + 每档勾选 + 每档手填价差(≥0.3%兜底)
- 上下端分开填（空头重→上端远、下端近）
- **作用**：失衡每升一档就缩价差加速锁利

### ② 失衡率回补（分批）· 中等 ← 修正：放在单向防御前面
- **触发**：失衡 ≥ 回补触发(滑块，默认**20~30%**)
- **目标**：降到回补目标(滑块，默认10%)
- **分批**：2~3批，先补一半观察再补
- **默认降到中性**(各50%)；趋势只做可选增强(占优%默认0)
- 每批：`N = (净敞口−目标净敞口)÷2÷批数`，双向各半，总持仓不变
- 执行：挂限价→N分钟未成交分批转市价；回补后重算锚点

### ③ 单向防御 · 较重 ← 修正：触发值应 > 回补
- **触发**：失衡 ≥ 单向阈值(滑块，默认**50~60%**，必须 > 回补触发)
- **动作**：只平重仓侧、不逆势开新仓
- 空头重→只挂下端(平空+开多)，撤上端；退出带迟滞
- **作用**：失衡更高、回补已处理过但仍升上来时，最后的调仓防线

### ④ 安全距离兜底（全平）
离强平 < 阈值 → 全平

### ⑤ 失血熔断（全平）
权益速跌 + 安全距离缩（双确认）→ 全平

### ⑥ 滚动止盈（全平）
盈利达递增档 → 全平

---

## 二、触发值必须递增（前端约束，防打架）

```
收网档位 < 回补触发 < 单向阈值
  20%    <   30%    <  50~60%
```

**前端硬约束**：回补触发值必须 > 收网最大档位，单向阈值必须 > 回补触发值。否则保存时弹错。

---

## 三、决策链（每tick）

```
安全距离 < 阈值          → 全平(④)
权益速跌+安全距离缩       → 全平(⑤)
盈利达递增档             → 全平(⑥)
失衡 ≥ 单向阈值(50~60%)  → 单向防御(③)   ← 最高失衡，最后调仓防线
失衡 ≥ 回补触发(30%)     → 分批回补(②)   ← 中等失衡，主动调平
失衡 ≥ 收网档位(20%)     → 缩价差收网(①) ← 轻度失衡，渐进化解
否则                     → 正常网格跑
```

---

## 四、联动要点（防打架）

1. **触发值递增**：收网20 < 回补30 < 单向50~60，前端硬约束
2. **回补分批**：先补一半观察，反转损失小
3. **回补默认中性**：趋势只做可选增强，不押方向
4. **调仓三件套永不全平**：只有安全距离/失血/止盈才全平
