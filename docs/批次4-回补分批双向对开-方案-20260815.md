# Grid-V2.0 批次4：失衡回补改"分批双向对开"实现方案（2026-08-15）

> 状态：方案已确认，待落码。基于 adjust.py:_do_rebalance 重构。

---

## 〇、改动对比

| | 现状 | 定稿 |
|:--|:--|:--|
| 动作 | 市价单向减重仓侧 | **分批双向对开**（平重仓N + 开轻仓N，总持仓不变）|
| 张数 | rebalance_contracts(单边净敞口) | `每批=(净敞口−目标净敞口)÷2÷批数` |
| 批数 | 单次 | **滑块 2~3批，默认2** |
| 挂单 | 市价 | **限价贴近盘口**（买→买一，卖→卖一），超时转市价 |
| 批间间隔 | — | **滑块，默认20分钟**（5/15/30可选）|
| 限价超时 | — | **默认10分钟，滑块可调** |
| 趋势 | — | 观察模式，默认中性不押方向 |

---

## 一、张数计算（双向）
```
净敞口 = |多−空|
目标净敞口 = 总持仓 × 目标失衡率%
总需平 = 净敞口 − 目标净敞口
每批 = 总需平 ÷ 2 ÷ 批数     ← ÷2 因双向(平重仓+开轻仓)
```

## 二、双向对开（每批）
```
重仓空：平空N(买) + 开多N(买) → 总持仓不变，多空更均衡
重仓多：平多N(卖) + 开空N(卖)
```

## 三、挂单价（贴近盘口）
```
买方向(平空+开多) → 挂 buy 限价 = bid_px(买一)   → maker 秒成
卖方向(平多+开空) → 挂 sell 限价 = ask_px(卖一)   → maker 秒成
```
（超时10分钟未成交 → 转市价兜底，分批转避免大滑点）

## 四、分批执行
- 批1：挂限价(盘口价) → 等批间间隔
- 批2：价格没反转再补
- 全部批完成后重算锚点

## 五、趋势观察模式
- 默认降到中性（各50%），不押方向
- 趋势信号仅展示+记录验证，不参与决策

## 六、新增参数（models/state/routes/前端）
| 参数 | 默认 | 滑块 |
|:--|:--|:--|
| `rebalance_batches` | 2 | 2~3 |
| `rebalance_batch_gap_min` | 20 | 5/15/30 |
| `rebalance_limit_timeout_min` | 10 | 1~60 |

## 七、注意：不影响正常网格滚仓
- 回补只在 `失衡≥触发 且 use_rebalance 开启` 时介入
- 回补后重算锚点，不破坏网格挂单方向
