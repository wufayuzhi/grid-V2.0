> 依据：今天 PIEVERSE 实盘完整轨迹（10%~35%失衡演变）推导，不猜。

## 〇、核心原则（用户定）

1. **决策看"仓位对比"，不是机械失衡率** —— 调滑块时实时预览"当前总仓下该失衡率对应 多:空 多少张"。
2. **控制灵活** —— 档位/回补都用滑块 + 直接手填差值（不用密度公式），0.3%手续费下限兜底。
3. **机制极简** —— 砍掉 OI(摆设)、累计回撤(虚报)、单向防御(被回补取代)。能调仓化解绝不全平。

## 一、失衡率仓位预览（前端必做，纯计算）

**公式（已验证，324:396@10%吻合）**：
```
当前总张数 T = 多 + 空（建仓后随时间滚动的实时值）
失衡率 x% → 净敞口 = x% × T
→ 多 = (T + 净敞口) ÷ 2 ,  空 = (T − 净敞口) ÷ 2
```

**要预览的位置**（每个滑块下方实时显示）：
| 滑块 | 预览"当前仓下" |
|:--|:--|
| 回补触发%(如60%) | 失衡60% ≈ 多546:空137 |
| 回补目标%(如40%) | 失衡40% ≈ 多478:空205 |
| 档位1~5 失衡率 | 每档对应 多:空 |
| 单向阈值(若保留) | 对应 多:空 |

**作用**：你拖滑块就能直观看到"这个失衡率 = 仓位偏到多少"，不用脑算。

## 二、档位密度收网（改：直接填价差，非密度公式）

**档位**：5档失衡率（滑块设定，如40/50/60/70/80），**每档勾选启用**，勾几档启用几档。
**控制方式（用户定）**：**取消"密度×ATR%"公式，直接手填价差**（差值%）。
- 每档填"收网后挂单离锚点多少%"
- **系统强制 `max(填的值, 0.3%)`**（0.3% = 手续费兜底，防止填太小每单亏手续费）

**上下端分开（空头重 为例）**：
- 上端(平多+开空，会累加空头) → 填远端价差（如3~4%），尽量不加重空头
- 下端(平空+开多，化解空头) → 填近端价差（如1%），尽快化解
- 多头重对称：上端近、下端远

## 三、失衡率回补（改：仓位对比 + 看权益）

**触发/目标双滑块**（0-100）：
- 触发滑块：失衡率到多少开始回补（**建议默认 30%**，数据推导见下）
- 目标滑块：回补到多少（**建议默认 10%**）

**回补动作分级（用户定）**：
- **大失衡**（触发值很高，如≥60%）→ 双向开平（平重仓X + 开轻仓X），让两边快速归平衡
- **非大失衡**（常见档）→ **最优单边**：优先平重仓侧（锁盈利/降险）；若要开轻仓侧，**必须先算权益金够不够**（`可用权益×杠杆÷(面值×价)`），不够则只平不开

**回补执行**：挂限价贴近行情价；**N分钟(建议10~30)未成交 → 分批转市价兜底**（防单边趋势不成交/大滑点）。回补后重算网格锚点 = 新多空均价中轴。

## 四、真实样本推导的回补触发值（不猜）

今天 PIEVERSE 失衡10%→35% 的**净浮盈演变**：
```
失衡10%  净-19   温和，震荡能化解 → 不干预
失衡15%  净-19   温和
失衡20%  净-44   恶化2倍 → 开始收网
失衡25%  净-54   持续恶化
失衡30%  净-101  失控加速 → 触发回补
失衡35%  净-132  → 熔断全平
```

**推导结论**：
- **收网档位**：失衡20%开始缩价差（20%/25%两档）
- **回补触发**：**30%**（净浮盈失控加速点）——你之前说"不会调到80%"，正确，30%就该动了
- **回补目标**：10%（回到正常区）

> ⚠️ 这只是1个样本的推导，**建议值可调**（滑块），后续多跑几轮用真实数据校准。

## 六、决策链（每tick）

```
安全距离<阈值 → 全平
权益速跌+安全距离缩 → 全平
盈利达档 → 全平
失衡≥触发(30%) → 回补(看权益,分级)
失衡≥收网档(20%) → 缩价差收网
否则 → 正常网格跑
```
