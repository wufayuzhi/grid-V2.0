## 二、重构总纲：统一风险标尺

**一句话：风控一律以「真实账户权益 + 单边暴露」为准，砍掉"浮盈回吐"这种假信号。**

```
风险 = max( 权益回撤风险 , 单边暴露风险 )
     ├─ 权益回撤 = (权益峰值 − 当前权益) ÷ 本金基准        ← 真实，已含已实现利润
     └─ 单边暴露 = 失衡率 = |多−空| ÷ (多+空)             ← 仓位危险度总指挥
```

## 三、逐层重构设计

### 第 1 层：真实权益回撤（取代累计回撤虚报口径）— 🔴 最高优先

**改前**（现在，错的）：
```
回撤 = (浮盈峰值 − 当前浮盈) ÷ (权益 − 累计追加) × 100%
       peak_upl = 自上次全平/重建以来最高【浮盈】(tick 层 max 更新)
```
**改后**（目标，对的）：
```
回撤 = (权益峰值 − 当前权益) ÷ (本金基准 − 累计追加) × 100%
       peak_equity = 自上次全平/重建以来最高【真实总权益】(total_equity 的 max)
```
**效果**：已实现利润天然算进权益 → 不再虚报。08-15 那次若用此口径：权益峰值1500.42→当前1402.59，回撤=(1500.42−1402.59)/1489.74≈**6.6%**，低于阈值10%，**不会误全平**。

**改动点**：
- `models.py`：`peak_upl` → 新增 `peak_equity`（保留 peak_upl 兼容展示，或直接替换）
- `engine/tick.py:125-128`：把对 `_latest_upl` 取 max 改为对 `total_equity` 取 max
- `formulas/drawdown.py`：公式分子改为 `peak_equity − total_equity`
- `engine/adjust.py:_check_cumulative_drawdown`：传入参数改为 peak_equity/total_equity
- `engine/build.py:158`、`engine/flat.py`：全平/建仓重置改重置 peak_equity

## 四、调仓唯一责任人决策（关键）

**问题**：现在 adjust.py 失衡回补 和 grid.py 档位收网 都在动仓位，可能打架。

**方案 A（推荐）**：**grid.py 档位密度收网为唯一调仓责任人**
- 失衡高 → 收网（缩间距、单向防御），不回补不砍仓
- 全平只留给"真风险"：失血 / 真实权益回撤 / 止盈 / 手动
- 优点：符合你"失衡高只收网、不主动砍仓"的定案，行为单一可预期

**方案 B**：保留失衡回补为可选手动触发
- 需明确与收网不冲突（同一失衡不双触发）
