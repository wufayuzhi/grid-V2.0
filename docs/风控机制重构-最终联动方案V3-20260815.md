# Grid-V2.0 风控机制重构 · 最终联动方案 V3（修正顺序：单边防守在回补前）

> 用户定稿顺序：收网 → 单边防守 → 回补 → 全平兜底。
> 核心：回补是最重调仓动作(=重新开网格)，单边防守在它前面继续盈利。

---

## 〇、触发顺序（用户定稿）

```
失衡 0% → 收网(20%) → 单边防守(25~29%) → 回补(30%+) → 全平兜底
           缩价差        挂单边继续盈利      重开网格      危险
```

**逻辑链**：
1. **收网**：失衡20%起，缩价差，还能双向挂单正常跑
2. **单边防守**：失衡突破到25~29%，开始只挂单边(顺势侧)，**尽量继续盈利、不砍仓**
3. **回补**：单边防守也守不住(失衡≥30%)，才回补(=主动平仓+加仓，重新开网格)
4. **全平**：安全距离/失血/止盈才全平

---

## 一、六个机制

### ① 档位密度网（收网）· 最轻
- 5档失衡率滑块(默认20/25/30/35/40) + 每档勾选 + 每档手填价差(≥0.3%兜底)
- 上下端分开填（空头重→上端远防累加、下端近快化解）
- **作用**：失衡每升一档就缩价差，渐进化解

### ② 单边防守 · 中等（在回补前）
- **触发**：失衡 ≥ 单边阈值(滑块，默认25~29%) 且 重仓侧浮亏(防抖30s)
- **动作**：只挂"平重仓侧+开轻仓侧"（顺势侧），撤"会加重重仓侧"的单
  - 空头重→只挂下端(平空+开多)，撤上端
  - **不砍仓、不主动平仓**，靠挂单边继续盈利磨失衡
- **退出（带迟滞）**：失衡 < (阈值−5%) 或 重仓转盈 → 退出防横跳

### ③ 失衡率回补（分批）· 较重（最后调仓手段）
- **触发**：失衡 ≥ 回补触发(滑块，默认30%，必须 > 单边阈值)
- **目标**：降到回补目标(滑块，默认10%)
- **分批**：2~3批，先补一半观察再补
- **默认降到中性**(各50%)；趋势只做可选增强(占优%默认0)
- 每批：`N = (净敞口−目标净敞口)÷2÷批数`，双向各半，总持仓不变
- 执行：挂限价→N分钟未成交分批转市价；回补后重算锚点
- **本质**：重新开网格

### ④ 安全距离兜底（全平）
离强平 < 阈值 → 全平。保留（失衡率≠爆仓距离）

### ⑤ 失血熔断（全平）
权益速跌 + 安全距离缩（双确认）→ 全平。防插针

### ⑥ 滚动止盈（全平）
盈利达递增档 → 全平落袋

---

## 二、触发值递增（前端硬约束）

```
收网最大档位 < 单边阈值 < 回补触发
    20%      <  25~29%  <   30%+
```
保存时校验，不递增弹错。**杜绝配出打架数值**。

---

## 三、决策链（每tick）

```
安全距离<阈值           → 全平(④)
权益速跌+安全距离缩       → 全平(⑤)
盈利达递增档             → 全平(⑥)
失衡 ≥ 回补触发(30%)     → 分批回补(③)   ← 最后调仓手段
失衡 ≥ 单边阈值(25~29%)  → 单边防守(②)   ← 挂单边继续盈利
失衡 ≥ 收网档位(20%)     → 缩价差收网(①) ← 渐进化解
否则                     → 正常网格跑
```

---

## 四、联动要点

1. **触发值递增**：收网20 < 单边25~29 < 回补30+，前端硬约束
2. **回补分批**：先补一半观察，反转损失小
3. **回补默认中性**：趋势只做可选增强，不押方向
4. **调仓三件套永不全平**：只有安全距离/失血/止盈全平
5. **单边防守=继续盈利**，回补=重新开网格，回补最重放最后
