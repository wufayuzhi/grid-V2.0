# Grid-V2.0 风控机制重构 · 最终联动方案（2026-08-15）

> 综合全部讨论结论。核心原则：**能调仓化解绝不全平；回补分批不押方向；全平只留真危险**。
> 状态：**联动设计定稿，待用户逐条确认后出代码方案。**

---

## 〇、总原则

1. **按失衡率从轻到重分级响应**，先调仓、后全平
2. **回补分批**（不一步到位），**默认降到中性**（趋势只做可选增强，不默认押方向）
3. **全平只留给真危险**：安全距离(离爆仓近)、失血(权益速跌)、止盈(赚够)
4. **砍掉**：累计回撤(浮盈虚报)、OI(摆设)、单向防御被回补取代

---

## 一、六个机制的联动与设置

### ① 档位密度网（收网）· 最轻
**作用**：失衡轻度，靠缩价差加速锁利、渐进化解
**设置**：
- 5档失衡率 = **滑块**（如20/30/40/50/60），每档**勾选启用**
- 每档**手填价差**（直接填%，不搞密度公式），系统强制 `max(填的, 0.3%)` 兜底手续费
- **上下端分开填**：空头重→上端挂远(防累加空头)、下端挂近(快速化解)；多头重对称

**联动**：失衡回落到档位以下 → 自动回到对应档密度（档位实时生效）

---

### ② 单向防御（只平重仓侧）· 中等
**作用**：失衡较重/趋势单边时，只平重仓侧、不逆势开新仓
**设置**：失衡率 ≥ 单向阈值(滑块, 如60%) 且 重仓侧浮亏(防抖30s) → 进入单向模式
**动作**：
- 空头重 → 只挂"平空+开多"(下端)，撤"会加重空头"的上端单
- 多头重 → 对称
**退出（带迟滞）**：失衡 < (阈值−5%) 或 重仓转盈 → 退出，防来回横跳

---

### ③ 失衡率回补（分批·双向开平）· 较重
**作用**：收网+单向都拦不住时，主动把失衡压回目标
**设置**：
- 回补触发滑块（失衡到多少开始，如30%）
- 回补目标滑块（降到多少，如10%）
- **分批**：不一次补完，分2~3批（如先补一半→观察→确认再补）
- **默认降到中性**（各50%）；趋势信号只做**可选增强**（确认强时才加顺势头寸，占优%默认0）

**回补动作（分批，每批）**：
```
回补量 N = (当前净敞口 − 目标净敞口) ÷ 2 ÷ 批数
每批 = 平重仓 N 张 + 开轻仓 N 张（双向各半，总持仓不变）
```
**执行**：挂限价贴近行情 → N分钟未成交 → **分批转市价兜底**（防单边不成交/大滑点）
**回补后**：重算网格锚点 = 新多空均价中轴

---

### ④ 安全距离兜底（全平）· 危险
**作用**：离爆仓太近，保命
**设置**：离最近强平价 < 阈值(滑块) → 全平禁重建
**保留理由**：失衡率≠爆仓距离（失衡5%高杠杆也可能爆）

---

### ⑤ 失血熔断（全平）· 危险
**作用**：权益速跌，拔网线
**设置**：`权益速跌(阈值%/N秒) 且 安全距离缩到阈值内` → **双确认**才全平
**防插针**：插针时价格拉回、安全距离没缩 → 不触发

---

### ⑥ 滚动止盈（全平）· 赚够
**作用**：赚够落袋，重新开仓
**设置**：盈利达递增档(每24h升一档) → 全平(可自动重建)

---

## 二、决策链（每tick，从重到轻检查，一触发即执行）

```
安全距离 < 阈值            → 全平 (④)
权益速跌 + 安全距离缩       → 全平 (⑤)
盈利达递增档               → 全平 (⑥)
失衡 ≥ 回补触发(30%)       → 分批回补 (③)
失衡 ≥ 单向阈值(60%)+重仓亏 → 单向防御 (②)
失衡 ≥ 收网档位(20%)        → 缩价差收网 (①)
否则                       → 正常网格跑
```

---

## 三、机制联动要点（防打架）

1. **回补优先于单向防御**：失衡先到回补触发(30%)就回补，单向防御(60%)是回补还没拦住时兜底
2. **回补分批降风险**：分2~3批，先补一半观察，确认趋势再补；反转损失小
3. **趋势只增强不依赖**：回补默认中性，趋势信号确认强才加顺势头寸(占优%默认0)
4. **全平只留危险**：只有安全距离/失血/止盈才全平，调仓三件套(收网/单向/回补)永远不触发全平

## 四、参数总览（前端滑块/输入）

| 机制 | 参数 | 类型 |
|:--|:--|:--|
| 收网 | 5档失衡率 + 每档价差 + 每档勾选 | 滑块+输入+勾选 |
| 单向防御 | 单向阈值% | 滑块 |
| 回补 | 触发% + 目标% + 批数 + 占优%(默认0) | 滑块 |
| 安全距离 | 阈值% | 滑块 |
| 失血 | 权益速跌% + 时间窗 + 安全距离系数 | 滑块 |
| 止盈 | 递增档盈利% | 滑块 |
