## 〇、统一风险标尺与核心原则

```
风险 = max( 单边暴露风险 , 爆仓空间风险 )
     ├─ 单边暴露 = 失衡率 = |多−空| ÷ (多+空)        ← 总指挥，决定调仓动作
     └─ 爆仓空间 = 安全距离 = 离最近强平价 %         ← 最后兜底，决定是否全平
```

**两条铁律**：
1. 能调仓化解的，绝不先全平；全平只留给"真爆仓风险"。
2. 所有回补/调平/对锁动作 = 挂限价单 + **超时转市价兜底**（防单边趋势限价不成交导致保护失效）。

**已删除**：累计回撤兜底（浮盈虚报，无正面作用）。

## 一、执行顺序（从轻到重）

```
① 档位密度网（收网）   失衡轻度，渐进化解
② 单向防御             失衡较重/趋势单边，只平重仓侧防加重
③ 失衡率回补           收网+单向都拦不住，双向开平主动调平
④ 安全距离兜底(全平)   离爆仓太近保命
⑤ 失血熔断(全平)       极端速跌，双确认兜底
⑥ 滚动止盈(全平)       赚够落袋
⑦ 手动对锁/全平        人工干预
```

## 二、机制①：档位密度网（收网 · 渐进化解）

### 2.1 定位
失衡**轻度**时的第一道防线。不砍仓，通过缩网格间距加速成交、锁定利润、渐进化解失衡。

### 2.2 触发与档位
```
失衡率 ≥ 档位阈值 → 缩密度（可勾选启用）
档位表：40%→密度1.4 / 50%→1.0 / 60%→0.75 / 70%→0.5 / 80%→0.3
```
档位为**阶梯**：失衡率落在某档以上 → 用该档密度。失衡回落 → 密度自动回弹。

### 2.3 间距计算（核心修正：上下端分开）
间距下限 = 单笔手续费可覆盖价差（**严谨推导**）：
```
fee_pct = 单边费率(取交易所实际，约0.1%单边)
间距下限% = max( 2 × fee_pct × 安全系数 , 密度×ATR% )
         = max( 2×0.1%×1.5 , ... ) ≈ 0.3%   ← 至少覆盖往返手续费
```

**上下端分开挂（以空头重 多100/空500 为例）**：
```
重仓侧 = short（空多）
上端（平多+开空，会累加空头）→ 挂远端：
    upper_px = anchor × (1 + 间距_远)   间距_远 = max(间距下限, 3~4%)
    目的：尽量不累加重仓侧（空头）
下端（平空+开多，化解空头）→ 挂近端：
    lower_px = anchor × (1 − 间距_近)   间距_近 = max(间距下限, 1%)
    目的：尽快触发化解重仓侧（空头）
```
多头重时对称：上端近、下端远。

### 2.4 防坑
- **趋势确认上涨 + 空头重** → 上端单（会开空）**不挂或挂极远**，避免涨势里继续加重空头。
- 密度被密度下限(max)钳制，不缩到手续费以下（否则每单亏手续费）。

## 三、机制②：单向防御（只平重仓侧）

### 3.1 触发
```
失衡率 ≥ 单向阈值(默认60%)  且  重仓侧浮亏(防抖确认30s)
```
### 3.2 动作
只挂"平重仓侧 + 开轻仓侧"单，撤掉"会加重重仓侧"的单。
```
空头重(461>222) → 只挂下端(开多+平空)，撤上端(开空)
多头重          → 只挂上端(平多+开空)，撤下端(开多)
```
### 3.3 退出（带迟滞，防来回切）
```
退出 = 失衡率 < (单向阈值 − 缓冲)  或  重仓侧转盈
缓冲 exit_buffer = 5%（防抖/迟滞，防在阈值附近来回横跳）
```

### 3.4 防坑
方向必须 = 重仓侧**反方向**。绝不做加重重仓侧动作。

## 四、机制③：失衡率回补（双向开平 · 主动调平）

### 4.1 触发（两条路径任一）
```
路径A：失衡率 ≥ 回补触发值(默认80%) 且 收网+单向已生效仍拦不住
路径B：24h 单向防御无成交  且  安全距离持续缩小（今天 PIEVERSE 场景）
```
### 4.2 动作：挂限价单，双向开平，贴近行情价
```
例：多100 / 空500（失衡67%）
净敞口 = |100−500| = 400
调平张数 = min( 净敞口 ÷ 2 , 单边可开上限 ) = min(200, 单边上限)
→ 平重仓侧 200 张（平空200 → 剩300）
→ 开轻仓侧 200 张（开多200 → 变300）
→ 结果 300:300 平衡 ✅
```
**不是单方向平400**（避免爆拉/砍在低点）。双向分摊，两边各动一半。

### 4.3 挂单执行（关键防坑）
```
挂限价单贴近当前价 → 若 N 秒(默认30s)未成交 → 转市价兜底
```
**为什么必须转市价**：单边趋势里限价单挂在下方/上方可能永远不成交 → 保护失效。
**回补后**：重算网格锚点 = 新多空均价中轴（否则后续挂单价失真）。

### 4.4 防坑
- 调平张数不超单边可开上限（查 get_max_size）。
- 回补触发值必须 > 回补目标值（触发80% > 目标40%），否则拒绝。
- 回补有冷却（≥ data_loop_interval×3），防每tick重复下单。

## 五、机制④：安全距离兜底（全平 · 最后防线）【保留】

### 5.1 定位
失衡率只看张数不对称，**不看价格离爆仓多远**。高杠杆下失衡率5%也可能逼近强平。**必须保留**。

### 5.2 公式与触发
```
安全距离 = | 重仓方向强平价 − 当前价 | ÷ 当前价 × 100%
触发：安全距离 < 阈值 → 全平 + 禁重建
阈值 = max( (维持保证金率 + 1/杠杆) × 安全系数 , 数据推导值 )
```
完全对冲（多空相等）→ 安全距离=999%（超级安全，不触发）。

## 六、机制⑤：失血熔断（全平 · 双确认兜底）【建议保留】

### 6.1 现状问题
5秒3%插针（长影线）可能误触发，其实离爆仓还远。

### 6.2 修正：双确认
```
触发条件 = 权益回撤超阈值(3%/5s)  且  安全距离缩小到阈值1.5倍以内
插针：价格瞬间拉回 → 安全距离没缩小 → 不触发 ✅
真单边暴跌：权益速跌 + 离强平近 → 触发全平 ✅
```
### 6.3 效果
既防插针误杀，又保极端兜底。**不建议删除**（删了失去极端行情保护）。

## 七、机制⑥：滚动止盈（全平）【保留】

```
盈利% = (当前总权益 − 本金基准) ÷ 本金基准 × 100%
止盈线随建仓时长递增：第n个24h档 = n × 1%
触发：盈利% ≥ 当前档位 → 全平（可重建）
```
加独立开关 `use_tp`。

## 八、机制⑦：手动对锁 / 全平【保留】

- **对锁** = 开弱势侧拉平净敞口（挂限价 + 超时转市价）。
- **全平** = 紧急市价双向平仓。

---

## 九、机制⑧：建仓安全系数（头寸控制）【保留】

```
建仓张数 = 交易所最大(maxBuy/maxSell取小) × 安全系数(0.7)
对冲双开：每边 = min( maxBuy, maxSell ) ÷ 2 × 0.7
```
**防坑：建仓保留市价等量双开**（不用限价），保证双边同时成交，避免建仓即单边。

## 十、机制⑨：趋势信号接入失衡率

### 10.1 作用
趋势方向决定"回补/收网的急迫度"（顺势急、逆势缓）。

### 10.2 规则
```
上涨趋势 + 空头重 → 回补"平空+开多"是顺势 → 更快更积极执行（缩短冷却、贴近挂单）
上涨趋势 + 多头重 → 回补"平多+开空"是逆势 → 谨慎/延后（拉长冷却、挂更远），先靠收网
下跌趋势 → 对称处理
震荡 → 正常回补
```
### 10.3 实现
趋势信号（trend.py，当前未接线）→ 作为回补/收网的**方向权重修正系数**，不改变方向本身，只调急迫度。

## 十一、决策链伪代码（每 tick）

```
1. 算 失衡率、安全距离、权益、趋势方向
2. if 安全距离 < 阈值 → 全平(④)
3. elif 权益速跌 且 安全距离缩小 → 全平(⑤失血双确认)
4. elif 盈利 ≥ 止盈档 → 全平(⑥)
5. elif 失衡率 ≥ 单向阈值 且 重仓在亏 → 单向防御(②)
6. elif 失衡率 ≥ 回补触发 或 (24h单向无成交 且 安全距离缩小) → 回补(③)
7. else → 档位密度收网(①)
8. 回补/收网方向 由趋势修正(⑨)
```

## 十二、参数表（建议值 + 滑块可调）

| 参数 | 建议值 | 推导/说明 |
|:--|:--|:--|
| 单向阈值 | 60% | 进入单向防御 |
| 回补触发 | 80% | 触发主动调平（须>目标）|
| 回补目标 | 40% | 调平后目标失衡率 |
| 间距下限 | 0.3% | 2×单边费率×安全系数 |
| 单向无成交窗口 | 24h | 触发回补路径B |
| 安全距离阈值 | 由1/杠杆推导 | 全平线 |
| 失血阈值 | 3%/5s | 双确认 |
| 失血安全距离倍率 | 1.5× | 双确认条件 |
| 限价转市价超时 | 30s | 防限价不成交 |
