## 〇、总纲：统一风险标尺

**核心思想**：风控一律以「**真实账户权益 + 单边暴露(失衡率)**」为准，砍掉"浮盈回吐"假信号。
**最高原则**：能调仓化解的，绝不先全平。全平只留给"真爆仓风险"。

```
风险 = max( 单边暴露风险 , 爆仓空间风险 )
     ├─ 单边暴露 = 失衡率 = |多−空| ÷ (多+空)          ← 总指挥，决定调仓动作
     └─ 爆仓空间 = 安全距离 = 离最近强平价 %           ← 最后兜底，决定是否全平
```

---

## 一、执行顺序（从轻到重，能化解就不全平）

```
1. 档位密度网（调仓收网）     ← 失衡轻度，先渐进化解
2. 单向防御（只平重仓侧）     ← 失衡较重/趋势单边，防止加重
3. 失衡率回补（双向开平）     ← 收网+单向都拦不住，主动调平
4. 安全距离兜底（全平）       ← 离爆仓太近，保命
5. 失血熔断（全平）           ← 极端速跌，双确认兜底
6. 滚动止盈（全平）           ← 赚够了落袋
7. 手动对锁 / 手动全平        ← 人工干预
```

**删除**：累计回撤兜底（浮盈虚报，无正面作用，你已定案）。

## 二、机制详解

### ① 档位密度网（调仓 · 渐进收网）

**触发**：失衡率 ≥ 档位阈值（40/50/60/70/80%，可勾选）
**动作**：缩网格密度（挂单间距变密），**上下端分开调整**

**修正后的间距设计**（你提的核心）：
- 间距**下限** = 单笔手续费可覆盖的价差（当前费率约0.3%，即单笔至少不亏手续费）
- **不再只用密度算**：失衡高时这是"止损收网"，不是正常吃差价挂单
- **上下端分开**（以空头重为例：多100/空500）：
  - **上端**（开空平多）→ 挂远（3-4%）：**尽量不累加重仓侧（空头）**
  - **下端**（开多平空）→ 挂近（1%）：**尽快化解重仓侧（空头）**
- 反向同理：多头重 → 上端挂近、下端挂远

**防坑（BUG3/4）**：趋势确认上涨时，**上端单（会开空）不挂或大幅拉远**，避免涨势里继续加重空头失衡。

---

### ② 单向防御（调仓 · 只平重仓侧）

**触发**：失衡率 ≥ 单向阈值（60%）**且** 重仓侧在亏（防抖确认，30s）
**动作**：**只挂"平重仓侧 + 开轻仓侧"的单，撤掉"会加重重仓侧"的单**
- 空头重（461>222）：只挂下端（开多+平空），撤上端（开空）→ 你已定
- 多头重：只挂上端（开多... 即平多+开空），撤下端

**防坑**：方向必须=重仓侧的**反方向**（空重就做多方向），绝不做加重重仓侧的动作。

---

### ③ 失衡率回补（调仓 · 主动双向调平）

**触发**：收网 + 单向防御都拦不住，失衡率仍超**回补触发值**（默认80%），**或** 24h 单向防御无成交但安全距离持续缩小（你提的今天 PIEVERSE 场景）
**动作**：**挂限价单，贴近行情价，双向开平**：
```
例：多100 / 空500（失衡67%）
→ 平重仓200（平空200 → 剩300）
→ 开轻仓200（开多200 → 变300）
→ 结果 300:300 平衡 ✅（不是单方向平400，避免爆拉/砍在低点）
```
**公式**：调平张数 = min( 净敞口 ÷ 2 , 单边可开上限 )
- 净敞口 = |多−空|，分到两边各平一半/开一半

**防坑（BUG1）**：**限价单必须带"超时转市价"兜底**——挂单 N 秒不成交 → 转市价，否则单边趋势里限价不成交=保护失效。
**防坑（BUG6）**：回补后**重算网格锚点** = 新多空均价中轴，否则后续挂单价失真。

---

### ④ 安全距离兜底（全平 · 最后防线）【保留，不能删】

**触发**：安全距离 < 阈值（离强平价太近）→ 全平禁重建
**人话**：失衡率只看张数不对称，**不管价格离爆仓多远**。高杠杆下失衡率5%也可能逼近强平——失衡率低≠离爆仓远。**必须保留**。

---

### ⑤ 失血熔断（全平 · 双确认兜底）【建议保留，加双确认】

**现状问题（你说的对）**：5秒3%插针（长影线）可能误触发，其实离爆仓还远。
**修正**：**"权益速跌 + 安全距离缩小"双确认**才触发：
- 插针：价格瞬间拉回 → 安全距离没缩小 → **不触发** ✅
- 真单边暴跌：权益速跌 + 离强平近 → 触发全平 ✅

**防坑（BUG7）**：既防插针误杀，又保极端兜底，**不建议删除**。

---

### ⑥ 滚动止盈（全平）【保留】

盈利达到递增档位（24h一档 1%/2%/3%…）→ 全平落袋。加独立开关。

---

### ⑦ 手动对锁 / 全平 【保留】

对锁 = 开弱势侧拉平净敞口（挂限价）。全平 = 紧急市价。

---

### ⑧ 建仓安全系数（头寸控制）【保留】

建仓张数 = 交易所最大 × 安全系数(0.7)。**防坑（BUG5）：建仓保留市价等量双开**，保证双边同时成交，避免建仓即单边。

---

### ⑨ 趋势信号接入失衡率【设计方向】

**作用**：趋势方向决定"回补/收网的急迫度"：
- **上涨趋势 + 空头重**（今天场景）→ 回补"平空+开多"是**顺势** → **更快更积极**执行
- **上涨趋势 + 多头重** → 回补"平多+开空"是**逆势** → **谨慎/延后**，先靠收网
- 一句话：**顺势急回补，逆势缓回补**

---

## 三、决策链伪代码

```
每 tick：
  1. 算失衡率、安全距离、权益、趋势方向
  2. if 安全距离 < 阈值 → 全平(④)
  3. elif 失血双确认(权益速跌 且 安全距离缩小) → 全平(⑤)
  4. elif 止盈达标 → 全平(⑥)
  5. elif 失衡率 ≥ 单向阈值 且 重仓在亏 → 单向防御(②)
  6. elif 失衡率 ≥ 回补触发 或 (24h单向无成交 且 安全距离缩小) → 回补(③)
  7. else → 档位密度收网(①)
  8. 回补/收网方向由趋势修正(⑨)
```
